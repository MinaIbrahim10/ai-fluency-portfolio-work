## Objective

This exercise focuses on visual judgment rather than decorative design.

The goal is to make deliberate visual choices that:

- create consistency,
- communicate a clear technical identity,
- keep project evidence easy to understand,
- and frame the work instead of upstaging it.

My existing portfolio was used as the real artifact for this review rather than designing a fictional portfolio from scratch.

### 2. Visual Identity Kit

The identity is designed around a restrained, technical, and professional presentation.

Core principles:

- consistent typography,
- limited accent colors,
- predictable spacing,
- reusable project-card structure,
- restrained visual effects,
- real technical evidence before decorative imagery.

### 3. Final Image Strategy

Preferred portfolio visuals:

1. Real product screenshots
2. Architecture and workflow diagrams
3. GitHub / open-source evidence
4. Research figures and charts
5. Technical illustrations
6. AI-generated imagery only when it adds information that real evidence cannot provide

[`image-selection.md`](image-selection.md)

## Visual Judgment Examples

### Agentic-Nexus

Prefer:

- architecture diagrams,
- agent orchestration flows,
- Hybrid RAG diagrams,
- repository evidence.

Reject:

- generic AI-agent artwork.

### TensorFlow Free-Threading Work

Prefer:

- real upstream pull requests,
- runtime results,
- release evidence,
- synchronization diagrams.

Reject:

- generic code or processor artwork.

### Hotel 1000

Prefer:

- actual product screenshots,
- dashboards,
- reservation workflows,
- analytics interfaces.

Reject:

- AI-generated hotel UI mockups when the real product exists.

### Research

Prefer:

- paper figures,
- data visualizations,
- experiment results,
- publication evidence.

Reject:

- abstract neural-network backgrounds.

---

## Rejected Visual Concepts

I deliberately rejected several common AI-portfolio visuals:

- glowing AI brains,
- humanoid robots,
- abstract neural-network backgrounds,
- generated UI mockups when real interfaces exist.

These visuals may look polished, but they provide less evidence than real engineering artifacts.

---

## Final Judgment

The strongest visual identity for my portfolio is not created by adding more imagery.

It comes from consistently presenting:

- real projects,
- architecture,
- measurable results,
- open-source contributions,
- research evidence,
- and production systems.

The design should make those artifacts easier to understand.

> Frame the work. Do not upstage it.
