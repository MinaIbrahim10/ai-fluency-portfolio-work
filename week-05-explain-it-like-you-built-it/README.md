# Explain It Like You Built It

## How My Cloudflare Pages Deployment Works

I used plain HTML and CSS to build a small live page.

At first, the source code was only stored locally on my machine, so after coding and previewing the website, only I could access that local version.

Cloudflare Pages helped me host the site publicly, so anyone with the URL can open the deployed version from anywhere.

Cloudflare serves the HTML and CSS needed to display the page, while the rest of my local files stay on my machine unless I publish them.

The main thing I learned is that building a website and hosting a website are two different steps. Writing the HTML and CSS creates the site, while deploying it makes that site available to other people on the internet.
